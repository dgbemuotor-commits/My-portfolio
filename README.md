# Deborah Florence Gbemuotor — Personal Portfolio

A responsive personal portfolio website for Deborah Florence Gbemuotor, an aspiring Software Engineer and Software Engineering Intern at AMS1ONE Solutions.

## Visual direction
- Orange: primary accent
- Wine: headings, navigation accents, and dark sections
- White/cream: backgrounds and cards
- Responsive layout for desktop, tablet, and mobile

## Sections
- Home
- About
- Skills & interests
- Experience
- Projects
- Education
- Profile
- Contact

## Run locally
Open `index.html` in a browser, or serve the folder with any simple local web server.
